# Softer companions and an iPhone world

The native RealityKit companion renderer now runs on macOS 15+ and iOS 18+ within the existing Fonsters app. The world also runs on tvOS 26+. The iPhone home has an icon-only companion tab and the original gallery tab. Incoming legacy links select the original gallery before the existing import handler runs. The gallery, SwiftData/CloudKit configuration, original seeds, resolved descriptor version 1, PNG/GIF generation and old link codec are retained.

## Appearance and exploration

Groom version 3 uses shorter, thicker, curved wool-like fibers, dense close-up coverage, softer shared tuft normals, full roughness, low specular response and no clearcoat. Skin, horns, nose and the smile rim also lose the blanket clearcoat. This change targets the sharp, wiry and shiny look visible in the previous actual preview. It does not change the appearance descriptor or legacy raster. Eyes retain small highlights for expression.

The render-only happy mouth is wider with higher corners; greet/play open it further and quiet interactions soften it. Three hand-built solo settings—meadow, seaside and moonlit garden—replace the display platform. Every setting has depth and scenery behind the contact space. Autonomous solo steps cover more ground, start sooner, and alternate looking, hopping, waving, stretching and playing. The connected lobby retains its population-based garden, benches, fountain plaza, park and neighborhood. Arriving at a newly explored area produces a discovery reaction; walking, friend gestures and owner interaction remain interruptible. None of these autonomous actions train personality as if the owner had deliberately interacted.

## iPhone boundary

The phone uses the same geometry, groom, controllers, deterministic appearance fixtures, analytic touch volumes, world routes and friend simulation as the Mac. Native touch can stroke/hold a companion; tapping a path sends the selected friend there and dragging empty space turns the camera. Portrait selection, growing the local world, area navigation, passing a ball, dancing, benches, sound, pause and Still mode have compact native controls with accessibility names. Reduce Motion, Low Power and background suspension gate the shared clocks. A portrait original remains beside the close-up.

The iPhone currently offers the twelve local prototype fixtures; a saved gallery seed is not silently converted or enrolled. Connecting arbitrary supported owned gallery appearances to this world, visit-file sharing/review, typed Foundation Models controls, mic/camera consent UI, agent-program review and fictional social-profile studios remain Mac features to port. No external AI agent, multiplayer server or social-media account is connected. The existing paired-phone signing/profile is reused; no capabilities or user records are changed. Physical-device launch and visual/touch verification require an unlocked paired phone.

## Apple TV and opening the preview

tvOS 26 shows the same fuzzy world with native focusable area, portrait, friendship, camera, pause, Still and sound buttons. The remote's Play/Pause command is wired to pause. Older supported tvOS versions retain the original gallery, and RealityKit libraries are weak-linked. The TV has no finger-petting surface, microphone/camera controls, sharing studio or connected multiplayer service.

On the Air, double-click `script/Open Fonsters.command`, or run `script/build_and_run.sh --verify`. This uses the installed Xcode and stops only this checkout's exact prototype executable. Choose a meadow, seaside or moon icon; pet the coat or use the reaction icons; the group icon opens the growing local world. Sound stays opt-in. Replacements and the two new ambience requests are listed in [sound-effects-brief.md](sound-effects-brief.md); ambience is requested but not wired.
